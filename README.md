# LiapfBadge

A component description

## Installation

```bash
okalit add liapf-badge --registry github.com/your-org/your-catalog
```

Or manually copy to your project:

```bash
# The component will be installed in src/catalogs/liapf-badge/
```

## Usage

```js
import '@catalogs/liapf-badge/liapf-badge.js';
```

```html
<liapf-badge
  variant="solid"
  color="primary"
  size="0.7"
>
  Hello World
</liapf-badge>
```

## Props

| Name | Type | Default |
|------|------|---------|
| `variant` | `String` | `"solid"` |
| `color` | `String` | `"primary"` |
| `size` | `Number` | `0.7` |
